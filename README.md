# IIROSE 基础功能增强插件（哈基米南北绿豆） 
| 开关 | 默认 | 说明 |
|---|---|---|
| **暗度陈仓**（图床加速） | 开 | 接管官方上传链（面板选择/快速上传/粘贴三入口），图片改经 `img.scdn.io` 境内节点（`esaimg.cdn1.vip`）转存，仍按官方 `[url]` 格式回填公屏；第三方失败自动回退官方通道 |
| **覆水难收**（防止撤回） | 开 | 被撤回的消息不删除，以主题主色边框包裹保留原处可查看；自己的消息不拦截，刷新后失效 |
| **鬼鬼祟祟**（隐身切房） | 开 | 切换房间默认走官方隐藏式传送，公屏只显示上线与下线，不公开进房/切房提示 |
| **守株待兔**（红包助手） | 开 | `MutationObserver` 监听红包（编号卡片 onclick / `[.%xxxx]` 文本双通道），以官方同款指令 `inputKeyDown(moveinput,"小艾加入%…",1)` 即时加入；24h 持久化去重，特殊房间（`5bba34bd423d8` 前缀）自动用「大艾」 |
| **心中有数**（股价悬浮条） | 关 | 顶部实时股价悬浮条：股价 / 持股 / 总股 / 总金 / 余额，变动即时可见；点击调出炒股面板 |
| **销声匿迹**（隐藏点歌） | 关 | 兼容所有点歌渠道：劫持官方方法改写点歌事件，向服务器发送改写后的隐藏点歌包 |
| **百无禁忌**（违禁词放行） | 关 | 阻断官方前端违禁词检测，违禁消息不会被替换成 `***`；若官方后期增加服务端验证则失效 |
| **独善其身**（P2P 阻断） | 关 | 阻断所有 P2P 连接，强制使用官方中转服务器，去除 IP 侧漏风险 |
| **置身事外**（印象分隐身） | 关 | 隐藏印象分相关组件（眼不见心不烦）；不能阻止别人打分 |
| **耳根清净**（信箱静音） | 关 | 来信不再「叮」一声自动弹出信箱页：提示音与自动弹窗被掐断，消息照常进信箱与未读角标 |
| **摇头摆尾**（可爱尾巴） | 开 | 发送公屏/广播/私聊消息时结尾随机追加可爱尾巴（喵~ 啦~ 唔~ 等三十六种）；指令、点歌、红包、链接、空白艾特等场景自动跳过 |
| **一泻千里**（歌单滑动条） | 开 | 点歌房排序/切除选择器和媒体列表面板右侧加可拖动滑动条：拖到哪跳到哪，超长歌单一眼直达；列表不够长或面板收起时自动隐藏 |
| **变幻莫测**（气泡随机变色） | 关 | 每条发出的消息（公屏/私聊/花园）气泡以随机颜色示人（HSL 筛色不刺眼、连续不撞色），本地与对方所见一致；点歌分享卡除外 |
